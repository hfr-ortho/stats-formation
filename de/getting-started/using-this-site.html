So benutzen Sie diese Website

R oder Python wählen, die Beispiele selbst ausführen, die Hinweiskästen, wie Resultate berichtet werden und wie die Übungen funktionieren.

R oder Python einmal wählen

Jedes Beispiel auf dieser Website steht zweimal da: einmal in R und einmal in Python. Beide geben dieselbe Antwort. Klicken Sie auf einen Reiter, um zu wählen. Die Website merkt sich Ihre Wahl auf jeder Seite. Deshalb wählen Sie nur einmal. (Die Links EN, DE und FR oben auf der Seite ändern die Sprache des Texts, nicht die des Codes.)

Hier ein kleines Beispiel: das Alter von fünf erfundenen Patientinnen und Patienten, ihr Mittelwert und ihre Standardabweichung (SD).

  • R
  • Python
ages <- c(64, 71, 58, 69, 75)   # Alter von fünf erfundenen Patientinnen und Patienten

mean_age <- mean(ages)           # der Mittelwert
sd_age <- sd(ages)               # die Standardabweichung

mean_age
[1] 67.4
sd_age
[1] 6.580274
import pandas as pd

ages = pd.Series([64, 71, 58, 69, 75])   # Alter von fünf erfundenen Patientinnen und Patienten

mean_age = ages.mean()                    # der Mittelwert
sd_age = ages.std()                       # die Standardabweichung

print(mean_age)
67.4
print(sd_age)
6.580273550544841

Beide geben ein mittleres Alter von 67.4 Jahren mit einer SD von 6.6 Jahren an.

Tipp🔀 R oder Python: die Falle bei der Standardabweichung

Python kennt zwei gebräuchliche Arten, eine SD zu berechnen, und sie liefern unterschiedliche Werte. pandas (ages.std()) teilt durch n − 1, wie sd() in R. numpy (np.std(ages)) teilt durch n, ausser Sie schreiben np.std(ages, ddof=1). Medizinische Publikationen berichten die Version mit n − 1. Wo sich die Standardwerte der beiden Sprachen unterscheiden, legt diese Website sie ausdrücklich fest und erklärt in einem Kasten wie diesem, warum.

Im Hintergrund prüft jede Seite, dass die Antworten von R und Python übereinstimmen. Stimmen sie je nicht überein, wird die Website gar nicht erst erstellt. Sie können sich also darauf verlassen, dass beide Reiter dasselbe sagen.

Den Code selbst ausführen

  1. Öffnen Sie den Repository-Ordner in Positron (siehe Installieren & einrichten).
  2. Speichern Sie Übungsdateien im Ordner scratch/, zum Beispiel scratch/practice.R oder scratch/practice.py. Git ignoriert alles in scratch/. Übungsdateien können deshalb nie versehentlich in einen Commit gelangen.
  3. Kopieren Sie Code mit der Kopierschaltfläche, die oben rechts in jedem Codeblock erscheint.
  4. Führen Sie eine Zeile mit Cmd+Enter (Mac) oder Ctrl+Enter (Windows) aus. Positron schickt sie an die Konsole.

Datenpfade wie data/cohort.csv beziehen sich auf den obersten Ordner des Repositorys. Positron startet dort, wenn Sie den Ordner öffnen. Die Pfade funktionieren deshalb ohne weiteres.

Wie Resultate berichtet werden

Jeder Abschnitt «Resultate formulieren» auf dieser Website folgt denselben Regeln. Sie entsprechen dem, was die Gutachterinnen und Gutachter von Fachzeitschriften wie JBJS, The Bone & Joint Journal und CORR erwarten.

Was Berichten als Beispiel
Kontinuierlich, ungefähr symmetrisch Mittelwert (SD) Alter 67.4 (6.6) Jahre
Kontinuierlich, schief verteilt Median (IQR, Interquartilsabstand) Aufenthaltsdauer 1 (0 bis 2) Tage
Kategorien n (%) 312 (52 %) weiblich
p-Werte drei Dezimalstellen; nie «p = 0.000» oder «p = 1.000» p = 0.017; p < 0.001; p > 0.999
Effektschätzwerte mit einem 95%-Konfidenzintervall (KI) Differenz 1.6 kg/m² (95%-KI 0.7 bis 2.5)

Die Beispiele in der Tabelle sind Illustrationen, keine Resultate aus unseren Daten. Demografie (Tabelle 1) zeigt das vollständige Layout der Tabelle 1.

Results-Sätze nennen die Zahlen und hören dann auf: den Wert jeder Gruppe, den Schätzwert mit seinem 95%-KI und den p-Wert. Lassen Sie Wörter weg, die die Zahlen interpretieren, etwa «similar», «higher than», «more often», «improved», «significant», «no clear evidence», oder Etiketten wie «good» oder «moderate». Zu sagen, was die Zahlen bedeuten, ist Aufgabe der Diskussion. Ein Beispiel:

KOOS JR at 1 year was a median of 87 points (IQR 76 to 94) in men and 85 (IQR 73 to 94) in women (Hodges-Lehmann difference 1 point, 95% CI −2 to 4; p = 0.432).

Im Text rund um jeden Results-Satz interpretiert diese Website die Zahlen durchaus, denn so lernen Sie, eine Ausgabe zu lesen. Der Results-Satz selbst ist der Teil, den Sie in ein Manuskript übernehmen.

Übungen

Jede Seite endet mit zwei bis vier kurzen Übungen zu den Übungsdaten. Sie werden in drei Stufen schwieriger: dieselbe Analyse mit einer anderen Variable durchführen, für ein kurzes Szenario den richtigen Test wählen und dann den Results-Satz schreiben. Die Lösungen sind in beiden Sprachen verborgen. Versuchen Sie es zuerst selbst und prüfen Sie dann.

Probieren Sie es aus: Bestimmen Sie mit denselben fünf Altersangaben den Median.

ages <- c(64, 71, 58, 69, 75)

ages = pd.Series([64, 71, 58, 69, 75])
ages.median()   # 69.0
