15 · Tests post hoc et comparaisons multiples

Quels groupes diffèrent après une ANOVA, un test de Kruskal-Wallis, un test du khi-deux, un test à mesures répétées ou un test du log-rank, et comment garder les faux positifs sous contrôle.

Un test pour trois groupes ou plus pose une seule question : « y a-t-il une différence entre eux ? ». Quand la réponse est oui, la question suivante est de savoir quels groupes diffèrent de quels autres. Pour y répondre, il faut faire plusieurs tests à la fois, et chaque test de plus est une nouvelle chance de faux positif. Cette page montre comment comparer les groupes deux à deux en gardant cette chance sous contrôle. La plupart des sections « Après … » reprennent un exemple de la page 8, de la page 9 ou de la page 13.

Note💡 Comment cette page fonctionne

Exécutez les blocs de code dans l’ordre, de haut en bas : les blocs suivants utilisent les packages et les données chargés dans le premier.

Comme sur les pages d’où viennent ces exemples, les exemples de prothèses articulaires utilisent tous les cas, y compris les 80 patients opérés des deux côtés.

Pourquoi les tests multiples trompent

Un test au seuil de 5 % a 5 % de chances de donner un faux positif quand il n’y a vraiment aucune différence. Si vous faites plusieurs tests, ces chances s’additionnent. La probabilité d’au moins un faux positif sur un ensemble de tests est le taux d’erreur par famille de tests (family-wise error rate). Pour des tests indépendants au seuil de 5 %, il vaut 1 − 0.95k, où k est le nombre de tests :

  • R
  • Python

Quatre groupes font six paires. Six tests indépendants au seuil de 5 % donnent 26 % de chances d’au moins une fausse alerte, même s’il ne se passe rien ; vingt tests, 64 %. Les comparaisons deux à deux ne sont pas indépendantes, car chaque groupe figure dans trois des six paires ; pour quatre groupes de même taille, la probabilité est donc un peu plus basse : environ 20 %. C’est quand même quatre fois les 5 % que vous vouliez accepter. Comparer des paires exige donc un ajustement : une règle plus stricte qui maintient à 5 % la probabilité d’un faux positif quelque part dans l’ensemble des comparaisons.

Note💡 En clair

Achetez un billet de loterie : vous perdrez presque certainement. Achetez-en vingt : vos chances de gagner quelque chose augmentent. Chaque valeur p inférieure à 0.05 est un petit « gain », et avec assez de tests, il y en aura un par pur hasard. Ajuster les valeurs p rend chaque gain plus difficile à obtenir : la probabilité globale reste alors là où vous l’avez fixée.

Ajuster les valeurs p : Bonferroni, Holm et Benjamini-Hochberg

La page 8 a trouvé que l’âge diffère entre les quatre classes ASA. Voici les six comparaisons deux à deux, chacune un test t de Welch, avec les valeurs p telles quelles (non ajustées), puis ajustées de trois façons :

  • R
  • Python
age_pairs <- pairwise.t.test(cohort$age, cohort$asa, pool.sd = FALSE,      # les tests t de Welch
                             p.adjust.method = "none")
unadjusted <- age_pairs$p.value[lower.tri(age_pairs$p.value, diag = TRUE)]  # les six valeurs p, dans l'ordre des paires

adjusted <- tibble(pair = c("1 vs 2", "1 vs 3", "1 vs 4", "2 vs 3", "2 vs 4", "3 vs 4"),
                   unadjusted,
                   bonferroni = p.adjust(unadjusted, method = "bonferroni"),
                   holm = p.adjust(unadjusted, method = "holm"),
                   bh = p.adjust(unadjusted, method = "BH"))
adjusted |> mutate(across(-pair, \(p) round(p, 4)))

Suivez la comparaison ASA 1 contre ASA 2 sur la ligne : - Non ajustée, p = 0.022 : « significative » à elle seule, mais c’est l’un de six tests. - Bonferroni, p = 0.132 : multiplie chaque valeur p par le nombre de tests (ici 6). Simple, mais le plus strict : il écarte souvent de vraies différences. - Holm, p = 0.044 : une version descendante de Bonferroni. Il multiplie la plus petite valeur p par 6, la suivante par 5, et ainsi de suite, mais une valeur p ajustée ne peut pas être plus petite que la précédente dans cet ordre. ASA 3 contre 4 a la plus grande valeur p non ajustée (0.030) : elle est donc multipliée par 1, mais elle prend 0.044 à ASA 1 contre 2, celle qui la précède. Il contrôle le taux d’erreur par famille de tests aussi bien que Bonferroni et n’est jamais moins puissant : utilisez Holm plutôt que Bonferroni. - Benjamini-Hochberg (BH), p = 0.026 : contrôle autre chose, le taux de fausses découvertes : la part attendue de faux positifs parmi les résultats que vous déclarez significatifs. C’est le plus indulgent des trois. Il sert à passer au crible de nombreux critères à la recherche de pistes, pas à confirmer une affirmation.

Avertissement⚠️ Attention : décidez de l’ajustement avant de voir les valeurs p

Choisir l’ajustement qui garde significatif votre résultat préféré, c’est du p-hacking (la pêche à la valeur p). Choisissez à l’avance : Holm (ou une méthode conçue pour le test, comme celle de Tukey plus bas) pour les comparaisons que vous rapporterez comme des résultats, Benjamini-Hochberg seulement pour un criblage exploratoire. Dites dans les Méthodes lequel vous avez utilisé et combien de comparaisons il couvrait.

Après l’ANOVA : Tukey HSD et Games-Howell

Après une ANOVA à un facteur, le test HSD de Tukey (honestly significant difference) compare chaque paire de moyennes de groupes. Il tient compte de toutes les paires à la fois et donne à chaque différence un intervalle de confiance (IC) lui aussi ajusté. Il suppose que les groupes ont des dispersions semblables, comme l’ANOVA. Quand ce n’est pas le cas (le plus grand écart-type (ET) dépasse environ le double du plus petit), utilisez Games-Howell, la version de Welch du test de Tukey.

  • Python
age_anova <- aov(age ~ factor(asa), data = cohort)
age_tukey <- TukeyHSD(age_anova)                          # diff, IC à 95% ajusté, valeur p ajustée

Astuce🔀 R ou Python : Tukey et Games-Howell

TukeyHSD() de R et pairwise_tukeyhsd() de statsmodels donnent des résultats identiques ; R écrit les paires « 2-1 » (deuxième groupe moins premier), statsmodels écrit group1, group2 avec meandiff = group2 − group1. Pour Games-Howell, R a besoin du package rstatix ; en Python, pairwise_gameshowell() de pingouin donne diff comme A − B : ses signes sont donc l’inverse des estimations de R. Les valeurs p concordent.

Après Kruskal-Wallis : le test de Dunn

Le test de Dunn suit un test de Kruskal-Wallis. Il compare les rangs moyens des groupes issus du classement de Kruskal-Wallis : il mesure donc chaque paire sur la même échelle. Utilisez-le avec l’ajustement de Holm. Des tests de Mann-Whitney séparés recalculent plutôt les rangs pour chaque paire et demandent un ajustement à part.

La durée de séjour (LOS, de l’anglais length of stay) est asymétrique (la plupart des patients rentrent chez eux le jour 0 ou 1) : elle relève donc de la colonne des rangs. Diffère-t-elle entre les classes ASA ?

Après le khi-deux : tests exacts de Fisher deux à deux

Après l’ANOVA à mesures répétées : tests t appariés

La page 9 a trouvé que la fonction physique PROMIS a changé au cours de la première année, chez 328 patients mesurés aux quatre visites. Pour dire quand elle a changé, comparez chaque paire de visites avec un test t apparié et ajustez avec Holm :

  • R
  • Python
pf <- proms |>
  select(case_id, visit, promis_pf) |>
  group_by(case_id) |>
  filter(all(!is.na(promis_pf))) |>                  # patients mesurés aux quatre visites
  ungroup() |>
  mutate(visit = factor(visit, levels = c("preop", "6wk", "3mo", "1yr"))) |>
  arrange(case_id, visit)                           # les tests appariés associent les lignes par position

pf_pairs <- rstatix::pairwise_t_test(pf, promis_pf ~ visit, paired = TRUE, p.adjust.method = "holm")

Faut-il d’abord un test global significatif ?

Une règle courante dit : ne faites des tests post hoc que si le test global (l’ANOVA, Kruskal-Wallis ou le khi-deux) est significatif. Elle vient de la méthode de la différence minimale significative de Fisher (least significant difference), qui fait des tests deux à deux non ajustés et s’appuie sur le test global comme filtre. Ce filtre ne protège pleinement qu’avec trois groupes.

Les tests de cette page n’ont pas besoin du filtre. Le test HSD de Tukey et Games-Howell contrôlent le taux d’erreur par famille de tests tout seuls, et il en va de même du test de Dunn et de tout autre ensemble de tests deux à deux une fois l’ajustement de Holm appliqué. Exiger d’abord un test global significatif ne fait que les rendre plus stricts que nécessaire.

Les deux types de test peuvent aussi ne pas concorder, et ce n’est pas une contradiction : - Un test global significatif sans paire significative, comme pour les complications par classe ASA plus haut (p global = 0.016 ; aucune paire sous 0.05 après ajustement). Le test global rassemble les preuves des quatre classes, alors que chaque paire n’en utilise que deux, et les groupes ASA 1 et ASA 4 sont petits. Rapportez-le tel quel : les taux de complications différaient globalement entre les classes ASA, mais aucune paire de classes ne différait nettement. - Une paire significative sans test global significatif. Cela peut arriver quand une seule paire diffère et que les autres non : le test global s’en trouve dilué.

Que faire : 1. Décidez avant de regarder les données quelles comparaisons vous ferez : toutes les paires, ou quelques-unes planifiées. 2. Si votre question porte sur des paires, passez directement à une méthode deux à deux ajustée. Le test global est facultatif ; rapportez-le si vos lecteurs l’attendent. 3. Ne faites jamais de tests deux à deux non ajustés que vous n’aviez pas planifiés, quel que soit le résultat du test global. 4. Dites ce que vous avez fait dans les Méthodes.

Comparaisons planifiées et comment les rapporter

Toutes les comparaisons ne relèvent pas de la pêche aux résultats. Une étude qui compare un nouvel implant à l’implant standard a une comparaison prédéfinie, nommée dans le protocole avant toute collecte de données. Elle n’a besoin d’aucun ajustement, parce qu’elle n’est pas une comparaison parmi beaucoup d’autres. Si vous avez planifié trois comparaisons, comptez trois comparaisons dans l’ajustement, pas toutes les paires possibles.

Tout le reste est exploratoire : des comparaisons choisies après avoir vu les données, ou un balayage de nombreux critères. Comptez dans l’ajustement chaque comparaison que vous avez examinée, pas seulement celles que vous rapportez, et qualifiez les résultats d’exploratoires : ils suggèrent des questions pour la prochaine étude, pas des conclusions.

Methods: Pairwise comparisons after the omnibus tests used Tukey’s honestly significant difference test (after ANOVA), Dunn’s test (after Kruskal-Wallis) and Fisher’s exact tests (after chi-square), with Holm’s adjustment for multiple comparisons where the method did not adjust itself. All pairwise comparisons were exploratory.

Results: Across ASA classes, one-way ANOVA gave F(3, 596) = 23.9 (p < 0.001); in pairwise comparisons, the difference in mean age between ASA 3 and ASA 2 was 5.0 years (95% CI 3.0 to 6.9; p < 0.001). Table 2 gives all six pairwise comparisons.
